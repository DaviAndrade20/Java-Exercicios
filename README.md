# Exercícios de Java

Esse repositório guarda os meus exercícios e durante minha jornada de aprendizado em **Java**.

Eu curto pensar que eles não são apenas códigos. Estão também meus erros, minha ersistência, minhas dúvidas e minha evolução.

Cada exercício representa um pequeno passo na construção de algo maior: aprender a programar de verdade, desenvolver meu raciocínio lógico e me tornar um profissional cada vez melhor.

> **"Grandes coisas são feitas por uma série de pequenas coisas reunidas."**

## 🚀 Sobre este repositório

Os exercícios aqui acompanham meu aprendizado dos fundamentos da linguagem Java, passando por conceitos como:

* Variáveis e tipos de dados
* Operadores
* Estruturas condicionais
* Estruturas de repetição
* Métodos
* Arrays
* Orientação a Objetos
* Classes e objetos
* E outros conceitos que vou encontrando pelo caminho

Este repositório está em constante evolução. Conforme eu aprendo, novos exercícios e projetos são adicionados aqui.

## 📚 Minha jornada

Comecei a estudar programação porque quero construir coisas que sejam úteis, resolver problemas e entender cada vez mais o mundo da tecnologia.

Nem sempre é fácil. Às vezes um exercício simples parece complicado. Às vezes um erro de código faz perder horas. E algumas coisas precisam ser aprendidas mais de uma vez até realmente fazerem sentido. Mas faz parte.

**Aprender programação é uma jornada, não uma corrida.**

Este repositório é uma forma de registrar essa caminhada e poder olhar para trás algum dia e lembrar de onde comecei.
